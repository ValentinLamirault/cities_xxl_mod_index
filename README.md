# cities_xxl_mod_index
Index des mods pour cities XXL

Avec la disparition de nombreux sites dédiés à Cities XXL et à ses versions antérieures, les extensions moddées ont eu elles aussi tendance à disparaître. Cette page vous propose d'en retrouver 174. Les mods sont livrés tel quel sans garantie de support. J'utilise toute cette liste pour ma version de Cities XXL. Le crédit revient à leur auteur original.

Ce projet est là, pour que vous puissiez contribuer facilement à l'index des mods de cities XXL disponible sur mon site : https://www.vallamir-co.fr/cities_xxl_mods.php

L'idée étant que les descriptions, les titres, les auteurs et la catégorisation puissent être améliorées par la communauté n'ayant moi même pas suffisament de temps à consacrer à cet index.
